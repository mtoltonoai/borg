# Implementation v1 Specification

This directory contains authored specifications and proposals for the stable implementation identifier `v1`. [The main implementation specification](implementation.md) links the capability and phase documents prepared as the intended specification. COLLAB and its seven milestones have scoped implementation-spec approval; the 25 foundation capabilities and 93 foundation milestones remain proposed. Actual adoption status is kept in [review metadata](implementation-review.json), with [decision provenance](decisions.md). Normative presentation does not establish adoption or execution readiness.

Implementation code, tooling, tests, installed binaries, generated reports, retained execution artifacts and caches belong in the separate [borg-runtime repository](../../../../borg-runtime/README.md). [Current correction evidence](../../../../borg-runtime/artifacts/specs-only-yc8gxkus/README.md) records final paths, exact source identities, validation and phase-scoped relocation maps.
