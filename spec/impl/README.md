# Authored Implementation Specifications

[v1](v1/README.md) contains authored decisions, capability and phase specifications and proposals. Implementation repositories hold executable code and generated evidence separately. All implementations refer to the shared authoritative Borg contract; an implementation identifier is not a protocol version.

[v2](v2/README.md) contains the current implementation specification, decisions and execution plan. It preserves v1 and records differences from the shared contract; implementation and conformance evidence remain separate from planning associations.
