## Selected Boundary

Keep the complete native model-turn charter contract. For Codex, use the supported task and public outer-turn interface:

- Deliver the exact effective charter through the supported instruction surface and retain its authoritative source identity.
- Retain the actual delivery intent, acknowledgement, task, attempt and public turn association. A host delivery binding is distinct from model-declared clause references.
- Require genuine charter references on the supported final result. Retain any observed public metadata without claiming that it covers every internal model response.
- Exempt inaccessible internal model replies and next-inner-request boundaries from the initial Codex profile. Do not redefine the shared meaning of a model turn or claim full shared-contract conformance.
- Apply a running charter update only at an explicitly qualified safe public input boundary. Until such a boundary is qualified, retain the prior delivered revision and make the pending or unsupported update visible. A new task uses its selected charter; a future-task definition change does not rewrite an existing task.

This removes the need to modify or reverse-engineer Codex's inner loop for the initial release. It gives up per-internal-response charter auditing and immediate charter updates during an opaque running turn.
